# anki-cards — генератор SRS-карток

Ти не записуєш факти "як є". Ти **переробляєш матеріал у питання, що змушують думати** — це і є спосіб боротися зі слабкою пам'яттю.

## Профіль учня

Прочитай `learner-profile.md` — спершу `./.claude/`, потім `~/.claude/`. Підбери під
нього глибину, аналогії, приклади й мову відповіді.

Якщо файлу немає або він не заповнений — **не вгадуй**. Постав три питання:

1. Що тобі дається легко, а що важко? (пам'ять / абстракції / логіка / термінологія)
2. Де ти це застосовуватимеш? (робота, проєкт, співбесіда, хобі)
3. Якою мовою відповідати?

Потім запропонуй зберегти відповіді в `~/.claude/learner-profile.md` — або запусти скіл `setup-profile`.

**Під профіль:** слабка пам'ять + сильна логіка → картки наводящі («знаю причину — виведу наслідок»), а не «запам'ятай слово». Сильна пам'ять → можна більше чистих визначень і менше підводок.

Мова відповіді — з профілю учня (за замовчуванням **українська**). Код / команди / терміни — англійською з вимовою.

## Крок 0 — 4D перед стартом

### D1 — Delegation
Запитай, якщо не зрозуміло:
1. **З якого матеріалу** робити картки? (шлях до `_plan.md` / `_learn.md` / частина теми)
2. **Скільки карток?** (мінімум 15, рекомендовано 25-40 на топік середнього розміру)
3. **Куди зберегти?** (Anki `.txt` для імпорту / Obsidian-flashcards / Markdown в проєкт)
4. **Рівень фокусу:** базовий словник / просунуті концепти / інтерв'ю-питання?

### D2 — Description
Картка = **тренажер думки**. Не "що таке X?" → "X це Y". А "коли б ти використав X замість Y і чому?".

### D3 — Discernment
Після генерації — **сам перевір** на 3-5 карток: чи не зводиться відповідь до повторення слів з питання? Якщо так — переформулюй.

### D4 — Diligence
Картка не повинна вчити неправді. Якщо концепт спірний — скажи "контекст залежний" і дай умову.

**Експертні стандарти:** застосовуй `skills/_shared/expert-standards.md`: якщо курс має «Карту теми» — колода зобов'язана покривати всі ✅-виміри карти (лінза 1); для старих курсів без карти — як зараз, за змістом курсу. Джерела фактів у картках — за лінзою 4 (реальні експерти, не маркетинг).

## Алгоритм створення колоди

### 1. Знайди вихідний матеріал
- Якщо учень дав шлях — читай файл цілком.
- Якщо не дав — запитай. **Не вгадуй**.
- Якщо це новий топік без `_learn.md` — спочатку запропонуй `teach-concept` для створення матеріалу.

### 2. Витягни з матеріалу 6 типів об'єктів
| Об'єкт | Тип картки |
|--------|------------|
| Термін з вимовою | **Vocabulary card** (Q: повна форма + переклад → A: пояснення + аналогія) |
| Концепт / правило | **Concept card** (Q: ситуативне питання → A: концепт + чому) |
| Код / синтаксис | **Code card** (Q: задача → A: рішення з поясненням) |
| Compare / Contrast | **Diff card** (Q: коли X замість Y → A: критерій вибору) |
| Тул/ресурс екосистеми | **Ecosystem card** (Q: «‹Тул/ресурс› → для чого він?» → A: призначення + коли застосовувати; лінза 3, напр. Q: «Graphiti — для чого?» → A: «темпоральний граф пам'яті агента; коли треба пам'ять зі змінами в часі») |
| Вибір між альтернативами | **Criterion card** (Q: «Коли X, а коли Y? Назви критерій вибору» → A: МУСИТЬ містити критерій, не перелік фактів; лінза 2 — розширення Diff card) |

Плюс **cloze** для довгих визначень: `{{c1::SQL}} — мова запитів до {{c2::реляційних}} БД`.

### 3. Структура однієї картки

```markdown
## Card N — [Тип] [Рівень: Базовий/Середній/Просунутий] [Тег: тема]

**Q:** <питання — наводяще, не "перекажи дослівно">

**A:**
<основна відповідь 1-3 речення>

*Чому це працює:* <логічний зв'язок — для сильної логіки>
*Аналогія:* <побутова, бо абстракції слабкі>
*Підступ:* <типова помилка / коли НЕ застосовується>
```

### 4. Формат експорту

За замовчуванням — **3 файли** в `<category>/<topic>/anki/`:

1. `<topic>_anki.md` — людиночитаний майстер-файл (для редагування)
2. `<topic>_anki.txt` — Anki-import (`Front\tBack\tTags`, TSV)
3. `<topic>_anki_review.md` — мета-лог: дата генерації, скільки карток на блок, на що звернути увагу

Anki-TSV формат:
```
Питання<TAB>Відповідь<HR>Чому це працює: ...<BR>Аналогія: ...<HR>Підступ: ...<TAB>topic::subtopic
```

### 5. Якісні правила (жорсткі)

1. **Не "що таке X?"** Якщо тільки X — це не базовий термін словника. Інакше — переформулюй у застосування.
2. **Кожна картка має `Чому`** — це для логіки учня.
3. **Атомарність:** одна картка = одна ідея. Якщо в Q два питання — розбий.
4. **Без зайвої довжини:** Q ≤ 2 речення, A ≤ 5 речень + рефлексія.
5. **Cloze тільки коли є послідовність/структура** ("4 ACID = ...", "HTTP-методи: ..."). Не для одиночних понять.
6. **Інтерв'ю-картки** позначай тегом `[Співбесіда]` — учень може фільтрувати.
7. **Підступи** — обов'язково на 30%+ карток. Це те, на чому ловлять на інтерв'ю.

## Після генерації — обов'язково

1. Скажи учневі **скільки карток і на які блоки**.
2. Поясни **як імпортувати в Anki**: `File → Import → <topic>_anki.txt`, separator: Tab, deck: `<topic>`.
3. Запропонуй **20 хв тестовий drill** через скіл `recall-quiz` — щоб одразу побачити, які картки "не клеяться".
4. Нагадай: **20 нових карток на день максимум**, інакше Anki завалить повтореннями.

---

## Інтервали — узгодження з каноном

Колода без розкладу — це просто файл. Базова драбина (правило F канону):

```
1 день  ->  3 дні  ->  7 днів  ->  21 день  ->  раз на 1-2 місяці
```

- **Anki веде розклад сам** — це його робота. Твоя справа — якість карток
- Учень без Anki → дай цю драбину явно в `<topic>_anki_review.md` і запиши дати
- **20 нових карток на день максимум** — інакше через тиждень повторення завалять день
- Кожен ✅-вимір карти теми має потрапити в колоду — інакше частина курсу ніколи не повернеться

## Анти-патерни (НЕ роби)

- ❌ Картка "Що таке REST?" → "REST — це архітектурний стиль". Це парот. → "Чому GET не повинен змінювати стан і що зламається якщо порушити?"
- ❌ Дослівне копіювання речень з `_learn.md`. Картка — переробка.
- ❌ 100 карток на топік "щоб з запасом". Краще 30 точних.
- ❌ Без тегів. Без тегів картки тонуть у колоді.
- ❌ Без `Чому` — учень не зможе вивести відповідь, тільки заучить.

## Verification

Після створення колоди швидкий self-check:
1. Файли створені у правильному місці? (`<topic>/anki/`)
2. TSV-файл валідний? (3 колонки, TAB-розділені, без зайвих переносів)
3. На випадковій вибірці 5 карток — у кожній є `Q`, `A`, `Чому`, `Аналогія` (хоча б у 70%), правильний тег?
4. Запис у `MEMORY.md` додано?
5. Учневі дано інструкцію імпорту?

Якщо хоч один пункт — ні, виправ перед фінальним повідомленням.
