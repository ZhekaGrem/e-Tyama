# Профіль учня

Скопіюй цей файл у `~/.claude/learner-profile.md` і заповни. Або просто скажи асистенту
«налаштуй профіль» — скіл `setup-profile` проведе інтерв'ю і запише за тебе.

**Файл живе поза плагіном навмисно.** Оновлення плагіна перезаписує свою теку — профіль
усередині неї було б затерто.

Незаповнене лишай як `<?>`. Скіл побачить `<?>` і перепитає, а не вигадає за тебе.

---

## Мова

```
мова відповіді: <?>
```

Наприклад: `українська` · `English` · `українська, але терміни англійською`

---

## Як я вчуся

```
дається легко: <?>
дається важко: <?>
```

Це найважливіше поле — воно змінює **спосіб** пояснення, не тему.

| Якщо тут написано | Скіли поводитимуться так |
|---|---|
| важко: терміни, пам'ять | кожен термін = переклад + вимова + аналогія; більше інтервальних повторень |
| важко: абстракції | спершу конкретний приклад, теорія після нього |
| легко: логіка, ланцюжки | пояснення через «чому саме так», менше зубріння |
| важко: довгі тексти | коротші блоки з чекпойнтами замість полотна |

---

## Де я це застосую

```
робочий контекст: <?>
поточна ціль: <?>
рівень: <?>
```

Приклади робочого контексту: `бекенд на Python, інтеграції з платіжками` ·
`ремонтую техніку вдома` · `веду блог, монтую ролики` · `вчуся для себе`

Звідси скіли беруть **приклади**. Порожньо — приклади будуть побутові й загальні.

Рівень: `новачок` · `щось пробував` · `працюю з цим` — можна вказати по темах.

---

## Чим читаю матеріали

```
редактор: <?>
```

`vscode` — діаграми в `.md` рендеряться плагіном, тож скіли їх використовуватимуть.
Будь-що інше (`obsidian`, `github`, `телефон`, `блокнот`) — схеми будуть списками
й таблицями, які читаються скрізь.

Не знаєш — постав `<?>`, скіл спитає один раз.

---

## Де зберігати мої дані

```
сховище: <?>
```

Курси, логи квізів, статистика й ретро мають десь жити — інакше наступного разу асистент
не знатиме, де в тебе було слабко.

| Значення | Що це означає |
|---|---|
| `локально: F:\Навчання` | звичайна тека на диску. Працює в Claude Code |
| `drive` | тека `Tyama/` у Google Drive. Працює і з телефона, і з ноута; потрібен під'єднаний конектор |
| `немає` | нічого не зберігається. Асистент віддаватиме текст блоком для копіювання і **чесно казатиме**, що історії не буде |

Порожньо — асистент спитає один раз, коли вперше треба буде щось записати.

**Важливо:** асистент ніколи не скаже «зберіг», якщо не зберіг. Це правило D канону.

---

## Чого уникати

```
не роби: <?>
```

Приклади: `не пиши код за мене` · `без довгих вступів` · `не спрощуй, я не новачок` ·
`не хвали без причини`

---

## Приклад заповненого профілю

```
мова відповіді: українська

дається легко: логіка, причинно-наслідкові ланцюжки
дається важко: запам'ятовувати терміни, абстракції без прикладу

робочий контекст: бекенд-розробка, інтеграції зі сторонніми API
поточна ціль: пройти співбесіду на middle до грудня
рівень: працюю з цим, але без системи

редактор: vscode

не роби: не пиши код за мене, поки я не пояснив словами як воно має працювати
```
